# AOM Web Sitesi v2 – Yerelde çalıştırma (02-10-2026)

**Kısa yol:** `SITEYI_AC_03-10-2026.py` dosyasına çift tıklayın (Python 3 gerekir). Aşağıdaki adımları kendisi yapar ve tarayıcıyı açar.

Gerekli: Node.js 20 veya üstü (`node -v` ile kontrol edin). İlk çalıştırmada internet bağlantısı gerekir; Saira ve IBM Plex Sans yazı tipleri Google Fonts'tan indirilir.

1. Bu klasörde komut satırını açın: Gezgin'in adres çubuğuna `cmd` yazıp Enter'a basın.
2. Bağımlılıkları kurun (yalnızca ilk sefer): `npm install`
3. Geliştirme sunucusunu başlatın: `npm run dev`
4. Tarayıcıda açın: http://localhost:3003
5. Durdurmak için: Ctrl + C

Not: Eski site 3002 portunu kullanıyor; iki site aynı anda çalışabilir.

## Teknik

- Next.js 15.5.27 (güvenlik yamalı sürüm), React 19, TypeScript
- Stil: `src/app/globals.css` (AOM tasarım sistemi token'ları); ek kütüphane yok
- Logo: `public/aom-wordmark.png` (AOM tasarım sisteminden)
